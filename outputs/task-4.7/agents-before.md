# Portfolio Stellar Odyssey — Agent Instructions (Codex + OpenCode)

## Project Context
- React 19 + Vite 7 + Tailwind CSS 4 SPA portfolio
- Theme: Galaxy "Stellar Odyssey" / Mysterious / Premium Cinematic (Dark mode primary)
- 3D: React Three Fiber + Three.js + custom GLSL shaders (persistent canvas, scroll-linked camera)
- Animation: GSAP Club (FREE từ 2025) — ScrollSmoother, ScrollTrigger, SplitText, ScrambleText, Flip
- i18n: react-i18next (Vi mặc định / En)
- State: Zustand · Deploy: Vercel

## Rules
1. Luôn dùng functional components với hooks (JSX, không TSX)
2. Tailwind CSS 4 cho styling, KHÔNG inline styles
3. GSAP animations trong `useGSAP` từ `@gsap/react`, luôn cleanup
4. Theo đúng folder structure trong `src/` (3d/, components/, hooks/, i18n/, stores/, data/)
5. Mọi text content phải dùng i18n translation keys
6. Luôn xử lý `prefers-reduced-motion`
7. Zustand cho global state, KHÔNG React Context
8. Import paths dùng alias `@/`
9. Animation chỉ transform/opacity; thêm `will-change` tiết kiệm
10. Components 3D chỉ trong `src/3d/`; dùng `useFrame` thay setInterval

## Code Style
- JSX, ES modules
- Named exports cho components, default exports cho pages/sections
