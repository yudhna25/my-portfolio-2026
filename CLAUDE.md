# Portfolio Stellar Odyssey — Claude Instructions

## Overview
React 19 + Vite 7 SPA portfolio "Stellar Odyssey" — Galaxy/Premium Cinematic theme.
3D: R3F persistent canvas + custom shaders. Animation: GSAP Club (free) + ScrollSmoother.
i18n: Vi (mặc định) / En. State: Zustand.

## Review Focus
1. Accessibility: ARIA labels, keyboard nav, focus management, screen reader (WCAG 2.1 AA)
2. Performance: bundle size, render optimization, lazy loading, 3D quality tiers
3. Code quality: DRY, hooks rules, error boundaries, cleanup on unmount
4. SEO: meta tags, semantic HTML, Open Graph, structured data
5. Security: XSS prevention, external links `rel="noopener noreferrer"`
6. i18n: đầy đủ keys Vi/En, không hardcode text

## Writing Style for Portfolio Content
- Song ngữ: Vietnamese + English (chất lượng như nhau)
- Tone: bí ẩn, giàu trí tưởng tượng, tự tin — nhưng vẫn chuyên nghiệp
- Bio ngắn gọn, dẫn chứng bằng số liệu khi có thể
- Micro-copy: ngắn, rõ, có cá tính vũ trụ (Transmission, Voyage Log, Star Map...)
